# Concept Drift Detection in Machine Learning

## Team: Jair Mendoza, Pablo Alcolea Tortola, Jorge Martín de Valmaseda Sánchez

In machine learning, models are often trained under the assumption that the data they encounter will remain relatively consistent. However, in real-world applications, data characteristics and patterns can change over time. This phenomenon is known as concept drift.

In this project, we investigate different approaches to concept drift detection, exploring how they identify changes in data streams and how their performance varies under different conditions. We begin with synthetic datasets, particularly the SEA concepts, which allow us to control when and how drift occurs. We then evaluate selected methods using existing machine learning libraries, with the possibility of implementing additional approaches where needed.

Our goal is to compare these methods and understand their strengths and limitations, building a foundation for potential applications to real-world data, including biomedical signals.
